# Excellence Hospital Network

**Status: Work in Progress**

## Project Overview
A simulated hospital network built using Cisco Packet Tracer. The project aims to provide reliable connectivity between hospital departments while implementing network segmentation and security controls.

## Technologies
- Cisco Packet Tracer
- Cisco 3560 Multilayer Switch
- Cisco 2960 Access Switches
- VLANs and 802.1Q Trunking
- DHCP and Inter-VLAN Routing

## Network Design
- VLAN 10 — Administration
- VLAN 20 — Medical
- VLAN 30 — Guest Network
- VLAN 40 — Servers
- VLAN 99 — Management
